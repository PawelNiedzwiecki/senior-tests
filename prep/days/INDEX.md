# Daily schedule

One task, one day, in order. Generated from `prep/leetcode/` in a
teachability-first order (easiest/most foundational patterns first, hardest —
DP, backtracking — last), with a review day inserted every 5 new
problems that revisits the oldest problem in that block from scratch.

The original `prep/leetcode/` and `prep/tier-1/` folders are untouched and
stay the canonical reference (frequency-tiered); this folder is the actual
day-by-day driver.
